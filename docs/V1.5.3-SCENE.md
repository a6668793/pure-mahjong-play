# V1.5.3 昭和夜話牌桌

## 玩家資訊與防遮擋

將原本四個投影名牌改成獨立座位資訊區，明確標示自己、右家、對家及左家。保留原玩家名稱、真實分數、莊家／方位及回合標記；頭像按鈕沿用原更換人物事件。名稱單行省略，完整名稱保留 title；分數獨立顯示。

資訊區占用專屬排版空間，3D canvas 從其下方開始，資訊不與任何牌面共用空間。桌機四欄、手機直向兩欄兩排、手機橫向四欄。3D 投影點選座標加入場景上方保留高度，保證可點選區跟隨真正牌面，而不是只移動視覺。

## 無人物昭和場景與動畫

新場景 assets/showa-empty-parlor.webp 為內建 imagegen 生成的原創無人物像素場景（1536×1024，轉 WebP 約274KB）；不是參考截圖去除玩家的靜態展示圖。背景中無真人或人像，保留原本遊戲必要的玩家頭像 UI。

木格窗、深藍暖簾、燈籠、綠色吊燈、電風扇、時鐘、富士山圖與老式木殼電視形成統一場景。assets/showa-scene.js 與 table-3d.css 加入原創像素貓走動／擺尾、電視風景播放、吊飾微晃與暖光呼吸。裝飾層 pointer-events:none、aria-hidden:true，位於遊戲下方，不接收點擊，也不觸發引擎重新繪製。離開牌桌即移除，頁面隱藏暫停，系統 prefers-reduced-motion 時停用動畫。

最終生成提示詞：

Dark walnut wood, lattice twilight windows, indigo noren, paper lantern, olive pendant lamp, electric fan, plants, tea cups, soda bottles, wall clock and Mount Fuji landscape. 採用內建工具模式，未使用 API key 或任何新增付費服務。貓與電視動畫為專案原生 SVG／CSS，可重用。

## 驗證與界線

100 局核心自動對局、零和計分、引擎與保存程式碼不變、144 牌與20階級檢查通過。連續性回歸通過。瀏覽器已驗證選牌與打出四萬、四個分數來自原 DOM；桌機資訊區底部在 canvas 上方，不遮牌。

雲端以相同模型的 software-3d 驗證；仍不代表已完成 GPU 光影、實機 Safari／觸控效能與多人連線完整驗收。沒有更動任何帳號、分數、API、房間同步、規則或保存方式。

## 六尺寸最終複查

1920×1080、1440×900、1366×768、768×1024、390×844、844×390 均無整頁水平／垂直溢出。四個座位資訊皆保留；資訊區與3D場景的垂直間距分別為2、2、2、2、3、0px，沒有交疊。逐尺寸紀錄見 V1.5.3-overlap-results.json。瀏覽器亦確認四個原頭像 atlas 正常顯示、可開啟原人物選擇視窗，裝飾層不接收點擊，貓／電視動畫已運作。
