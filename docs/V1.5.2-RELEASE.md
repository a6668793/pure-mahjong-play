# V1.5.2 正式更新

依紅框參考圖移除單機牌桌右側工具列，將風圈、局數、連莊、底台設定與剩餘張數整組置中。動畫、電腦速度保留在上方設定；暫停／繼續、重播動畫及保存回首頁也收進設定視窗，原有功能及保存方式保留。

刪除模式切換控制與分支，刪除 assets/table-perspective.css，改用只負責通用排版的 assets/table-layout.css。正常遊戲只有立體場景。WebGL 不可用或 context lost 時以相同模型的 software-3d 繪製，並不是平面版本；兩種繪製後端都無法使用時顯示重試訊息，不顯示舊平面牌桌。

驗證：100 局核心對局、零和計分、受保護引擎與保存程式一致、20 階級及144牌標籤通過；連續性回歸通過。瀏覽器確認資訊列 justify-content:center、列內零按鈕、零模式切換控制；設定保留本局操作。沿用之前相同模型軟體繪製的出牌／摸牌連續性驗證。雲端環境仍無法提供 GPU 及真實手機效能驗收結果。

使用者本次明確要求更新正式網頁，完成以上修正與測試後部署；不修改任何 API 或重置任何玩家資料。
