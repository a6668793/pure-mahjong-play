# V1.5 立體昭和牌桌 — 測試預覽

## 範圍與結構

依《昭和麻將館的暖橙夜色》重構對局呈現。Three.js 0.170.0 本地託管（MIT 許可附於 assets/vendor/three.LICENSE），使用原創參數化幾何：厚木桌框、黃銅線、綠色織紋桌布、倒角象牙牌身與綠色牌背。使用同一個 PerspectiveCamera 及世界座標，包含直立手牌、平放捨牌、副露、花牌與逐層牌牆。這版沒有使用 Blender，也沒有把背景生成圖中的示意牌當成可操作牌。

assets/table-3d.js 是獨立呈現配接層，讀取原本已公開的牌桌 DOM；三家未公開牌仍只讀牌背，沒有存取隱藏牌。前景手牌以原本的 button 作為投影點選區，保留 onclick、disabled、aria-label、鍵盤與出牌確認方式。所有吃碰槓胡、房間命令、計分及保存沿用原程式。

WebGL 成功時使用 MeshStandardMaterial、場景燈光與陰影。WebGL 被停用時，assets/table-software-renderer.js 以 Canvas2D 逐像素深度緩衝、透視校正 UV 繪製相同 Three.js 模型；兩者都不能使用時保留原介面。玩家可用「牌桌：3D／相容模式」切換原介面。沒有新增儲存鍵、API 或付費依賴。

場景按狀態或尺寸變更繪製，閒置時不執行連續渲染。模型、牌面材質及 renderer 在選牌與出牌更新間重複使用；離開牌桌時釋放 WebGL 與幾何資源。牌面重用原 SVG 美術並移除原平面假厚度外框，改以模型呈現厚度。

## 驗證

- node tests/core.cjs：100 局完整 AI 對局通過，分數零和；遊戲及本機資料程式與原始基線相同。涵蓋出牌、吃、碰、明槓、暗槓、補槓及胡牌；20 階級及 144 張牌的標籤通過。
- 實際瀏覽器：原存檔繼續、前景手牌點選、打出四萬後牌河出現相同牌、三家後續回合均正常。
- 實際瀏覽器：合法「吃 5索 6索」按鈕可操作，副露實際顯示 4索、5索、6索，回到原出牌流程。
- 六尺寸檢查頁：tests/table-sizes.html，可切換 1920×1080、1440×900、1366×768、768×1024、390×844、844×390。手機直向可水平滑動場景，操作列獨立排列，橫向優先。
- 軟體繪製首次抽樣每次重繪約 87～329ms，隨畫布大小而異；這是雲端 CPU 環境的單次重繪時間，不能作為 GPU FPS 或真實手機效能的結論。

## 仍須驗收

雲端瀏覽器停用 WebGL，已驗證相同模型的軟體繪製與原介面備援；尚未以可用 GPU 的裝置驗證 WebGL 光影及效能。尺寸檢查是瀏覽器 iframe 檢查，不代表真實平板、手機觸控及 Safari 的完整驗證。好友房多人同步、斷線重連、帳號登入／註冊及完整一局的人手瀏覽器測試尚未完成；不可把核心自動對局當作上述項目均通過。

## 部署

獨立分支 ui/showa-3d-v1.5。正式 main 保持 V1.3.2，沒有覆蓋原站或重置任何玩家資料。先審查視角、牌面大小及實際裝置測試，再取得這版成果的明確同意後部署。V1.4 透視 CSS 保留作為相容顯示，新的 3D CSS 只在場景成功建立後啟用。
