# V1.6.0 手機橫向介面與條件操作列

## 改版

- 手機首頁使用緊湊導覽與場景／入口雙欄橫向布局；單機、好友房、階級、繼續場次皆可在第一屏操作。較小667px橫向也移除舊版堆疊空白，不會與下方桌種按鈕交疊。直向保留可捲動首頁，主要入口與規則／桌種資訊均保留。
- 手機橫向對局採100dvh可用高度，支援viewport-fit=cover及safe-area-inset，縮減導覽、狀態與座位資訊，保留完整手牌空間。沒有鎖定裝置方向或禁止縮放。
- 前景手牌仍使用同一個 Three.js scene、renderer 與真實牌模型。手機使用攝影機相對的前景擺位維持可讀尺寸；直向以兩排顯示。點選區以實際模型投影計算，旋轉後重新排版，桌機可回到原桌面座標。不是替換成平面SVG手牌。
- 移除憑空產生的停用吃／碰／槓／胡／過占位按鈕。保留原合法操作與所有選項、onclick、disabled條件。沒有可操作按鈕時整列隱藏；選取手牌後出現出牌確認；可吃碰槓胡時才顯示原合法選項與過。暫停、斷線或動畫鎖定時不顯示不可用按鈕。等待資訊保留在中央狀態。
- 登入、設定、人物、階級、好友房入口及必要視窗加上手機尺寸限制與內部捲動；原功能及資料來源不變。

## 驗證

- `node tests/core.cjs`：100局完整對局、零和計分、受保護引擎與本機資料程式一致、20階級及144牌標籤通過。
- `node tests/context-actions.cjs`：不產生占位按鈕、多組吃牌選項與原事件保留、原disabled狀態保留。
- `node tests/table-continuity.cjs`：動畫／摸牌／一般回合維持同一立體場景，單機及好友房同步掛載呈現層。
- 瀏覽器模擬：844×390、667×375、926×428橫向首頁主要入口都在第一屏；390×844直向入口也可正常顯示。
- 八尺寸對局檢查：1920×1080、1440×900、1366×768、768×1024、390×844、844×390、667×375、926×428無整頁溢出；所有前景手牌位於viewport內。667×375的16張手牌點選寬約41～47px，844×390約55～64px（實際尺寸隨牌數改變）。
- 實際操作：直向選牌後旋轉橫向保留選取；打出五萬後進入原牌河；合法碰北出現時只顯示「碰 北 北」與「過」，點碰後副露為北北北，操作列再次隱藏。
- 詳見 V1.6.0-mobile-results.json 與擴充的 tests/table-sizes.html。

## 尚未涵蓋

尺寸驗證為雲端瀏覽器iframe模擬，雲端WebGL停用時以相同模型的software-3d後端運行。尚非真實iPhone Safari、瀏海／主畫面手勢、觸控及GPU效能驗收。好友房多人同步、語音與重連本次未做完整實機測試；相關引擎、API、權限、計分與保存方式皆未修改。
