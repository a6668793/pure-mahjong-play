# V1.6.1 清晰舒適介面（測試預覽）

## 修改
- 全站導覽保留品牌、規則、設定，音效、音樂、登入、階級與紀錄放入「更多」。移動原按鈕，保留原事件。
- 桌機與手機牌局以可用視窗高度分配資訊、玩家、3D 場景與操作列。
- 回合提示移至資訊列，離開牌河。發牌提示使用保留區域。
- 手機 3D 手牌與牌桌使用分開的垂直空間；調整鏡頭視窗及牌厚度，保留真實幾何與原選牌事件。
- 操作列沒有可用操作時不可見，但保留高度，選牌前後牌桌位置不跳動；多個合法選項可水平捲動。
- 所有原生 dialog 加入固定在捲動上緣的關閉按鈕，限制視窗高度、內部捲動；繁體文字、表單、徽章保持可讀。
- index.html 與核心規則、API、帳號及儲存程式完全未改。本次由原有 3D 模組引入獨立介面增強模組。

## 驗證
- `node tests/core.cjs`：100 局，97 胡、3 流局；5224 出牌、617 碰、753 吃、16 暗槓、61 明槓、50 補槓。引擎與儲存保護區相同，20 階級與 144 牌標籤通過。
- `node tests/context-actions.cjs`、`node tests/table-continuity.cjs`、`git diff --check` 通過。
- 瀏覽器八種尺寸：1920×1080、1440×900、1366×768、768×1024、390×844、844×390、667×375、926×428，未見整頁溢出，HUD 與場景邊界分離，操作區在畫面內。
- 844×390 選牌前後牌桌矩形完全相同；原出牌按鈕可將六萬送入玩家捨牌區。
- 最終 926×428 修正：牌桌底 376px、手牌底 372.19px，無下緣裁切。
- 繼續場次、更多 → 階級、設定 → 完成、規則 → 新增關閉鈕皆正常；開啟階級時只有一個原生 dialog，無雙重視窗遮罩。
- 桌機 1366×768 與手機 844×390 實際畫面已檢查。

## 限制與部署
- 瀏覽器模擬尺寸驗證；未於實體 iPhone Safari 或 Android 進行觸控與 GPU 效能驗收。
- 未執行新的真人多人連線、登入註冊或語音完整回歸；相關核心完全未改。
- 手機橫向為了避免遮擋，牌桌與手牌分區；大桌面上的捨牌辨識度仍優於窄螢幕。
- 正式 main 保持 V1.6.0。依原要求，待使用者確認預覽及測試結果後才正式部署。
