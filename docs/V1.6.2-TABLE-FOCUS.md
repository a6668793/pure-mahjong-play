# V1.6.2 方位對話／全畫面牌桌預覽

## 改動
- 頁面內牌桌使用完整視窗高度，上方導覽及牌局資訊移入右上角可收合面板。原按鈕及事件保留，回首頁後原導覽回復。
- 四位玩家資訊移到各自方位；最近出牌文字依原牌河的方位顯示。當前回合提示在當前玩家旁顯示。
- 原吃碰播報節點移到對應玩家旁，保留原播報時間和音效，中央不再出現大型通知。無法識別玩家的播報保留於資訊面板，不猜測方位。
- 點回牌桌或按 Escape 可收起資訊面板；原生 dialog 保留自己的 Escape 行為。
- 減少牌桌上方占用，重新計算鏡頭及平板手牌；手牌、頭像、對話框分區。
- 未修改 index.html、遊戲引擎、AI、計分、網路協定、登入或儲存流程。
