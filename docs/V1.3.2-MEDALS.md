# V1.3.2 透明獎牌與裁切修正

將二十階獎牌改用獨立 RGBA WebP 透明素材，保留原本主題與像素金屬畫風，保護所有月桂、皇冠、翅膀及底部飾帶。每枚按自身 alpha 邊界等比例置入統一畫布，四邊保留透明安全區；SVG 使用 xMidYMid meet，避免拉伸與裁切。

圖鑑移除每枚獎牌的實色卡片背景、厚邊框與底板陰影；保留名稱、分數門檻、目前階級文字及未達成狀態。首頁、玩家資訊與牌桌名牌亦統一使用透明素材。

美術由內建 imagegen 依既有二十款主題製作透明版本，最終素材存放 assets/ranks-clear/。階級名稱、順序、積分門檻、玩家資料與任何遊戲邏輯均未改動。
