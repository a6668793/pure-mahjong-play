# V1.4 斜視角臨場牌桌（待視覺驗收）

以透視桌面、前景手牌及四方玩家重新安排單機與好友房的對局畫面。桌面使用可互動 DOM 上方的斜視木框／綠布平面，牌牆與四方捨牌區採相同透視方向；手牌保留在前景直立放大，摸進牌獨立分隔，選牌抬起，出牌／胡牌操作以酒紅按鈕區別。

資料與操作：四方捨牌分區僅重新排版公開的 discards 陣列，每筆仍保留牌值與出牌者 aria-label。好友房依目前使用者的座位轉換相對方向。每個分區可捲動保留完整捨牌，最新一張加金框。點選手牌後仍須按原有打出按鈕，無新增自動出牌、雙擊或規則判定。

原始 Game、AI、計分、GuestProfiles、階級門檻、帳號與網路契約不變。已有100局核心回歸通過，以及二十張獎牌與144張牌名稱檢查通過。新增視覺幫手 showaPerspectiveRiver，樣式獨立置於 assets/table-perspective.css，避免大幅覆寫既有非對局頁面。

需在預覽確認：前景手牌可選、出牌進入對應玩家分區、四個分區仍保留所有牌、方向映射、開局動畫、吃碰槓與結算、手機手牌橫向捲動及橫向模式。真人好友房連線與全尺寸仍需端到端驗收，不能以核心引擎測試取代。

正式部署仍依原任務，待測試成果供使用者檢視並取得明確同意。

預覽實測：1366px 寬桌面前景牌寬由舊樣式44px提高至約60px；選牌抬起22px；打出8萬後，該張進入本機玩家捨牌區，四方牌區皆存在。對家手牌已移至遠端桌沿。對局隱藏頁尾騰出空間，首頁頁尾保留。

固定操作列：出牌、吃、碰、槓、胡、過；僅移動既有已綁定事件的按鈕，保留同一操作的多個選項。沒有對應合法操作時，新增的是禁用顯示按鈕，不會呼叫遊戲引擎。
